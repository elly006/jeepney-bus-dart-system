# Dart Vehicle Management System

A Dart console app demonstrating OOP, abstract classes, mixins, and async programming — themed around Philippine public transport.

## ✨ Features
- Abstract `Vehicle` base class
- `Jeepney` with `Maintenance` mixin
- `Bus` class
- Passenger boarding with capacity check
- Async data saving (`async/await`)
- Vehicle info display

## 🚀 Run
```bash
dart vehicle_system.dart
